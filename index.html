The Engine

MILVIS — a copilot, not a surveillance system.

Mental Insight & Life-Virtue Integration System. MILVIS streams token-by-token over gRPC and executes work through sixteen tools that run on your device — creating tasks, logging journals, running resistance and burnout analysis over your own history.

Behind it, a five-provider cascade fails over automatically across roughly eight model attempts, so a reply always lands. Retrieval memory is 768-dimensional and stored locally in Isar — the vectors never leave the phone.

5Provider cascadeAutomatic failover, ~8 attempts
16Client-side toolsReal work on local repositories
768Dim on-device RAGCosine retrieval, true-LRU cap
5Chat personasCoach · Architect · Oracle · Commander · Chatbot
Offline-First

Your discipline is nobody else’s data.

The app is fully usable with the backend switched off. Persistence is local, ACID, and yours.

13 local collections

Tasks, journals, sprints, workouts, time logs, and RAG vectors live on-device in Isar — queried with zero network dependency.

Keys stay server-side

AI and embedding credentials live only in the backend env — never bundled in the client, never shipped to your device.

Works with the plug pulled

Every screen functions offline. The backend only exists to serve MILVIS — engage it when you choose, ignore it when you don’t.

Under the Glass

Engineered, not assembled.

A native Flutter client for Windows and Android, backed by a containerized Go gRPC server.

Client — Flutter

  • FrameworkFlutter 3.24.3 · Win + Android
  • StateRiverpod 2 + codegen
  • NavigationGoRouter · single shell
  • PersistenceIsar · 13 collections
  • UI engineImpeller · GLSL specular

Backend — Go gRPC

  • ServerGo 1.22 · Alpine ~15 MB
  • ProtocolgRPC :9090 · stream + unary
  • AI routing5-provider cascade
  • CacheRedis · SHA-256 · 24h TTL
  • Embeddings768-dim · OpenAI-compatible
